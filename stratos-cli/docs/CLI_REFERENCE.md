## Global options

| Name | Kind | Description |
|---|---|---|
| `--version` | option | Show version and exit. |

## Exit codes

| Code | Meaning |
|---|---|
| 0 | Success |
| 1 | General error |
| 2 | Invalid usage (bad command line) |
| 3 | Authentication failure (not signed in, bad credentials) |
| 4 | Authorisation failure (missing permission or blocked by policy) |
| 5 | Resource not found |
| 6 | Validation failure (bad input) |
| 7 | Network or API error |
| 8 | Configuration error |
| 9 | Dependency error (missing tool, failed `doctor` check) |
| 10 | Operation cancelled |

## Environment variables

See `.env.example`. Settings use `STRATOS_<SECTION>__<KEY>`; credentials use provider variables such as `GITHUB_TOKEN` and `ANTHROPIC_API_KEY`.
